# Changelog

## 0.2.0 - 2026-09-14

### Added

- Offline command to reproduce the five native bit-order rows from separately
  obtained configuration inputs, with size and SHA-256 checks before parsing.
- Input-access instructions, expected output and interpretation of that comparison.
- Ten synthetic regression tests for the command, bringing the suite to 115 tests.
- Pinned source-file inventory and supporting line references for the article's
  upstream scoring and stage-policy observations.

### Compatibility

The six library modules and seven earlier test modules are unchanged.
External input bodies are not bundled. This release adds reproducibility
tools, not a new receiver algorithm or sequencing-recovery result.

## 0.1.0 - 2026-09-14

### Added

- Complete-stream bit and byte scoring with explicit within-byte bit order.
- Permutation, sparse matrix, code-membership and watermark mapping checks.
- Reference systematic encoder and flooding sum-product decoder.
- Bounded synchronization, observation-identity handling and soft demapping.
- Seven synthetic test modules and three documented usage examples.
- Explicit input validation for directly constructed parity-check matrices.
