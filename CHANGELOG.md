# Changelog

- Complete-stream bit and byte scoring with explicit within-byte bit order.
- Permutation, sparse matrix, code-membership and watermark mapping checks.

- Bounded synchronization, observation-identity handling and soft demapping.
- Seven synthetic test modules and three documented usage examples.
- Explicit input validation for directly constructed parity-check matrices.
